# 硬件接线

两板均为 3.3V 逻辑电平，信号线直连即可，无需电平转换。杜邦线建议用短一点的。

## 板间连线

### 必需（3 根信号线）+ 供电（1 根）

| # | 经典 ESP32 (WROOM) | 方向 | ESP32-S3 | 说明 |
|---|---|---|---|---|
| 1 | GPIO17（TX2） | → | GPIO18（RX） | HCI 数据：经典 → S3 |
| 2 | GPIO16（RX2） | ← | GPIO17（TX） | HCI 数据：S3 → 经典 |
| 3 | GND | — | GND | 共地，**必须** |
| 4 | VIN / 5V | ← | 5V | 供电。**开发期两板各自 USB 供电时不接**；最终单 USB 形态时由 S3 板给经典板供电 |

> 注意 TX/RX 是**交叉**的：一端的 TX 接另一端的 RX。

- 经典板侧引脚固定为 UART2 默认引脚（TX2=GPIO17, RX2=GPIO16）；
  UART0（板上 USB 串口芯片那个）保留给烧录和日志，不用于 HCI。
- S3 侧用 UART1 重映射到 GPIO17/18，均为普通空闲引脚。
- 固件配置（menuconfig/代码默认值）与本表严格一致，改线必须同步改文档和固件。

### 可选（2 根硬件流控线，先预留不接）

波特率从 921600 起步不需要流控；后续若升到 2M 提高吞吐时再接上：

| # | 经典 ESP32 | 方向 | ESP32-S3 | 说明 |
|---|---|---|---|---|
| 5 | GPIO4（RTS） | → | GPIO16（CTS） | "别发了"信号：经典 → S3 |
| 6 | GPIO13（CTS） | ← | GPIO15（RTS） | "别发了"信号：S3 → 经典 |

## USB 口分工

| 板 | USB 口 | 开发期用途 | 最终形态 |
|---|---|---|---|
| 经典 ESP32 | 唯一的 micro-USB 口 | 烧录 + 日志 | **不接电脑**（由 S3 供电） |
| S3 | 原生 USB 口（GPIO19/20） | 烧录 + 日志 | **蓝牙 dongle 数据口**（USB-OTG，class 0xE0） |
| S3 | 串口桥 USB 口 | 建议插上，作为专用烧录口更稳 | 不接电脑 |

S3 的两个 USB 口共用 GPIO19/20 的那对引脚是"USB-Serial/JTAG"和"USB-OTG"两个外设，
同一时刻只能用一个：烧录时是 Serial/JTAG，固件启动后切换为 OTG 枚举成蓝牙设备。
因此固件做好后，重烧 S3 需按住 BOOT 进下载模式，或改用串口桥口烧录。

## 端口实测（2026-10-23）

- `/dev/ttyUSB0` = 经典 ESP32（串口桥芯片）
- `/dev/ttyACM0` = ESP32-S3 原生 USB 口

## 接线后验证

```bash
ls /dev/ttyUSB* /dev/ttyACM*   # 应能看到上述两个串口
```

物理层验证（回路测试）等阶段 3 固件就绪后进行：固件内置 board-to-board 回环命令，
从一端 UART 发数据另一端应原样收到。
